# Checklist ménage — 85 Montée du Grès

> **Code de la boîte à clés : 1707**

## En arrivant

- [ ] Si possible, lancer une lessive de serviettes et de taies d’oreiller à **40 °C**.
- [ ] Étendre ensuite le linge dans la véranda.

## Salon et cuisine

### Nettoyage général

- [ ] Nettoyer les vitres à l’intérieur et à l’extérieur.
- [ ] Enlever les toiles d’araignée.
- [ ] Nettoyer les sols, y compris sous et derrière les meubles.
- [ ] Faire la poussière sur les ampoules de la cuisine.
- [ ] Arroser les petites plantes, s’il y en a.

> Les sols peuvent être nettoyés avec le Kärcher et le produit adapté, ou avec le seau et le balai.

### Cuisine

- [ ] Nettoyer les surfaces : façades des tiroirs, plan de travail et table en inox.
- [ ] Vérifier et nettoyer l’intérieur des tiroirs, qui peut contenir des résidus de nourriture.
- [ ] Vérifier la propreté des couverts et des plats rangés dans les tiroirs.
- [ ] Bien vérifier que l’intérieur du Thermomix est propre.
- [ ] Nettoyer l’intérieur du réfrigérateur avec du vinaigre.

### Salon

- [ ] Aspirer le canapé vert.
- [ ] Nettoyer le canapé en cuir avec de l’eau et un peu de savon de Marseille.
- [ ] Faire la poussière :
  - [ ] sur la table ;
  - [ ] sur et sous les chaises ;
  - [ ] sous les pieds des canapés et des meubles ;
  - [ ] sur et sous le piano ;
  - [ ] sur et derrière le poêle ;
  - [ ] sur la lampe située dans le coin.

## Salles de bain

- [ ] Nettoyer à fond les toilettes.
- [ ] Nettoyer la douche et les parois vitrées : elles doivent être impeccables.
- [ ] Nettoyer les miroirs.
- [ ] Nettoyer les lavabos.
- [ ] Nettoyer les sols.
- [ ] Vérifier et enlever la poussière sur les étagères et les vitres.

## Chambres

- [ ] Refaire tous les lits ; les draps propres se trouvent dans l’armoire.
- [ ] Laisser en place les protège-matelas et les protège-oreillers s’ils sont propres.
- [ ] Nettoyer les sols, y compris sous les lits.
- [ ] Faire la poussière sur les commodes.
- [ ] Bien enlever la poussière qui s’accumule sous les pieds des tables de chevet.
- [ ] Nettoyer les vitres.

## Véranda

- [ ] Bien nettoyer les sols.
- [ ] Enlever toutes les toiles d’araignée, qui s’accumulent rapidement dans cette pièce.
- [ ] Nettoyer les vitres accessibles.
- [ ] Nettoyer la table d’activités.
- [ ] Remettre en place ce qui aurait été déplacé.
- [ ] Arroser la plante située dans le coin.
- [ ] Faire la poussière autour du pot et de l’armoire.
- [ ] Remettre en place le drap du canapé et les coussins.

## Avant de partir

- [ ] Déposer sur la table le petit cadeau pour les invités :
  - [ ] une bouteille de vin ;
  - [ ] un savon au lait d’ânesse ;
  - [ ] la documentation de la maison.
- [ ] Vérifier qu’aucun jouet d’enfant ni aucun objet susceptible de prendre l’eau n’est resté dehors.
- [ ] Vérifier que toutes les lumières sont éteintes.
- [ ] Remettre la clé dans la boîte à clés.
